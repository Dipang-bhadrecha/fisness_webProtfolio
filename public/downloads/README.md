## FishToken Manager (Windows)

The installer is no longer hosted here. The `/fishtoken` page links to
`https://download.fisness.com` (`desktopInstaller` in `src/data/fishtoken.ts`),
a Cloudflare redirect to the newest GitHub release file. Publishing a new
release is enough: there is nothing to copy here and no version to bump.
